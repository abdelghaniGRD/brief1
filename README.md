# Brief 1: 🎯 Ce que j'ai appris

## 📌HTML and CSS

Introduction au HTML, qui assure la structure de la page, et au CSS (Cascading Style Sheets), qui en définit l'apparence : couleurs, polices, espacements, mise en page.
Concepts :

- Trois méthodes pour intégrer du CSS.

- Les sélecteurs : ce sont des modèles permettant d'identifier et de cibler les éléments HTML que vous souhaitez styliser. Ils font le lien entre votre structure HTML et vos règles CSS.

- Spécificité et héritage : ce sont les deux mécanismes fondamentaux déterminant quels styles s'appliquent à un élément lorsque plusieurs règles entrent en conflit.

- Couleurs, arrière-plans et bordures.

- Le modèle de boîte (box model) : une règle de mise en page fondamentale qui considère chaque élément HTML comme une boîte rectangulaire. Cette boîte détermine l'espace occupé par l'élément et la manière dont il interagit avec les éléments voisins sur la page web.

- Affichage (display) et positionnement (position) : deux propriétés essentielles pour contrôler la disposition et l'agencement des éléments sur une page web. Bien qu'elles fonctionnent de concert, elles ont des rôles distincts : `display` définit le comportement de l'élément dans le flux normal de mise en page, tandis que `position` détermine sa localisation et son décalage par rapport à ce flux.

- Flex (Flexbox) : un modèle de mise en page unidimensionnel conçu pour organiser, aligner et répartir l'espace entre les éléments d'un conteneur, même lorsque leurs dimensions sont dynamiques ou inconnues.

- Grid (CSS Grid) : un système de mise en page bidimensionnel puissant permettant de gérer simultanément les colonnes et les lignes.

- Responsive Web Design (RWD) : une approche consistant à créer des sites web dont la mise en page, la taille du texte et les images s'adaptent automatiquement pour offrir un rendu optimal sur tous les appareils, des petits écrans de smartphones aux grands moniteurs d'ordinateurs de bureau.
